# Remix of Safe Scan

Faça um web app capaz de anonimizar tomografias e gerar um novo zip sem dados pessoais; ele deve funcionar completamente off-line e ser completamente transparente com sua funcionalidade. Tendo link para abrir o código fonte no GitHub (será disponibilizado via GitHub Pages posteriormente) faça uma interface limpa que transmita transparência e confiança
